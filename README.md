# Advent Calendar 2026

A mobile-friendly advent calendar: 25 days, 25 quests, 25 surprises.

**Live:** https://george-1598.github.io/advent-calendar-2026/

## Develop

```bash
npm install
npm run dev
```

Add `?date=2026-12-05` (or `?date=2026-12-05T08:30`) to the URL to preview the calendar
as if it were that moment in Bucharest.

## Deploy

Every push to `main` builds and deploys to GitHub Pages through
`.github/workflows/deploy.yml`.
